# Telegram-бот с короткой памятью

Вариант домашнего задания: **короткая память** — бот помнит последние 10 сообщений диалога
и опирается на них в ответе.

## Как устроена память

Хранилище — словарь в оперативной памяти процесса:

```python
user_id -> deque(maxlen=10)   # роли "user" / "assistant"
```

- Ключ — `user_id`, поэтому у каждого пользователя своя история (память не смешивается).
- `deque(maxlen=10)` сама выкидывает самое старое сообщение, когда приходит одиннадцатое,
  — ручная обрезка не нужна.
- Сообщения чередуются: реплика пользователя → ответ бота → реплика → ответ.
- Память живёт в RAM: при перезапуске бота диалог пуст, `/reset` очищает окно вручную.

Библиотеки: `aiogram 3.x` (Telegram), `openai` (Chat Completions), `python-dotenv` (ключи).
Сторонние базы и векторные хранилища не используются — вся память в одном словаре.

## Логика одного запроса

1. Реплика пользователя добавляется в окно (`memory.add`).
2. Формируется запрос: `[system] + последние 10 сообщений` (`build_messages`).
   Системный промпт объясняет модели, что нужно учитывать историю диалога.
3. `await generate_reply(...)` — единственный вызов Chat Completions
   (синхронный SDK вызывается через `asyncio.to_thread`, чтобы не блокировать event loop).
4. Ответ модели кладётся в то же окно — следующий вопрос будет с контекстом.

Показать работу памяти можно так:

```
Пользователь: Меня зовут Аня
Бот:         Привет, Аня!
Пользователь: Как меня зовут?
Бот:         Тебя зовут Аня       ← ответ взят из истории, а не из текущего сообщения
Пользователь: А какой мой любимый цвет?
Бот:         Ты называла его два сообщения назад? Назови ещё раз —
             в окне из 10 сообщений первые реплики уже вытеснены
```

Команды: `/start`, `/memory` (сколько сообщений в окне), `/reset` (забыть диалог).

## Файлы

| Файл       | Назначение                                              |
|------------|---------------------------------------------------------|
| `bot.py`   | хендлеры aiogram, сборка запроса, точка входа            |
| `memory.py`| класс `ShortMemory` — окно диалога на пользователя       |
| `llm.py`   | вызов OpenAI + offline-заглушка без ключа                |
| `tests.py` | проверки обрезки окна, раздельности памяти и сборки запроса |

## Запуск

```bash
pip install -r requirements.txt
cp .env.example .env      # вписать BOT_TOKEN и OPENAI_API_KEY
python bot.py
```

Без `OPENAI_API_KEY` бот не падает: включается offline-режим, который показывает,
сколько сообщений из памяти ушло в запрос (полезно для демонстрации без траты токенов).

Проверки памяти:

```bash
python tests.py
```
